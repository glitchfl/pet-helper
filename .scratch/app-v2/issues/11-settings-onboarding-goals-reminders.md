# 11: Settings, onboarding, goals and reminders

**Status:** ready-for-agent

**Blocked by:** 06

## What to build

- **Settings:**
  - Exam Date and Daily Goal
  - Daily Reminder
  - appearance, text size and haptics
  - about and attribution, report, source code and version
  - reset progress
- A first-launch onboarding (Exam Date, Daily Goal, Reminder) that can be skipped.

## Acceptance criteria

- [ ] The reminder schedules, reschedules and cancels as the settings change, and permission denial is handled.
- [ ] Appearance and text size apply immediately.
- [ ] Reset clears Responses, Bookmarks and Attempts after confirmation.
- [ ] Onboarding shows once.
