# 10: Progress tab

**Status:** ready-for-agent

**Blocked by:** 06

## What to build

The Progress tab:
- summary tiles
- a 14-day activity chart with the goal line
- per-Domain coverage and accuracy
- accuracy per Question Type and per Topic, weakest first, with drill shortcuts
- average time per Question
- Attempt history

## Acceptance criteria

- [ ] Charts render in both themes and in RTL.
- [ ] Tapping a weak Question Type or Topic starts that drill.
