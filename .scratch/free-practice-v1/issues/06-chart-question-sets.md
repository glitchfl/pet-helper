# 06: Chart Question Sets

**Status:** ready-for-agent

**Blocked by:** 04 (Passage Question Sets), 05 (Quant display: math, Figures, image Options, Formula Sheet)

## What to build

When Free Practice reaches a Chart (a graph or table), you get the Chart and all the Questions that refer to it as one block, just like a Passage. The Chart stays reachable while you answer.

## Acceptance criteria

- [ ] Question Sets support the Chart kind: one image plus its Questions.
- [ ] A Chart Set is served as one unit and follows the same tier and no-repeat rules as a Passage Set.
- [ ] The Chart stays reachable while answering each of its Questions, on the light card.
- [ ] The sample bank gains a Chart Question Set.
- [ ] An engine test covers a Chart Set being served whole.
