# 08: Report a mistake

**Status:** ready-for-agent

**Blocked by:** 01 (Tracer: answer a sample Question on your phone)

## What to build

Every Question has a "report a mistake" button. It opens a new GitHub issue on the public pet-helper repo, already filled in, so you can flag a garbled formula or a suspicious Correct Option in seconds.

## Acceptance criteria

- [ ] Every Question shows a report button.
- [ ] The button opens GitHub's new-issue page for the public repo with the title and body prefilled: Exam, Section, Question number, Question id and app version.
- [ ] It works from Expo Go on an iPhone.
