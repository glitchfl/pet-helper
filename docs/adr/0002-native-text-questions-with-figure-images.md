# Questions stored as native text, only Figures and Charts as images

We store each Question as Hebrew text with math as typeset markup, and keep only Figures and Charts as images cropped from the PDF. The simpler alternative was to crop every Question from the PDF.

We rejected crops because A4 crops shrunk to phone width are hard to read and cannot adapt to dark mode. The cost is real: the PDF text layer loses √, fraction bars and π, so every Quant Question needs a manual pass checked against a Proof Sheet.

NITE's license forbids removing its markings, so the app draws the original watermark and copyright line behind every Question card instead of relying on the crops to carry them.
